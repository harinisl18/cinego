## ***Sprint 1 – Movie Listing and User Interface***



## **Goal**:

Create the basic website and display movies.



## **Tasks:**



Design the home page.



Display available movies with posters and descriptions.



Add movie search functionality.



Display movie details such as genre, duration, and language.



## **Deliverable**:

&#x20;A working website where users can browse and search for movies.



# ***Sprint 2 – Showtimes and Seat Selection***



## **Goal**:

Allow users to select a show and their seats.



## **Tasks:**



Display available theatres and showtimes.



Allow users to choose a date and time.



Display the cinema seat layout.



Allow users to select available seats.



Calculate the total ticket price.



## **Deliverable:**

&#x20;Users can select a movie, showtime, and seats.



# ***Sprint 3 – Booking, Payment, and Confirmation***



## **Goal**:

&#x20;Complete the ticket booking process.



## **Tasks**:



Collect customer details.



Display the booking summary.



Integrate a payment option or simulate payment.



Generate a booking confirmation with a ticket ID or QR code.



Test the complete booking process and fix errors.



## **Deliverable**:

&#x20;Users can complete a booking and receive ticket confirmation.
